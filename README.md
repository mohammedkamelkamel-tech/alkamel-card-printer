# الكامل-طباعة الكروت (`com.alkamel.cardprinter`)

تطبيق أندرويد محلي بالكامل باللغة العربية (دعم كامل لاتجاه RTL) لإدارة وتوليد وتصميم وطباعة كروت شبكات الإنترنت بمقاس **A4** باستخدام **Kotlin + Jetpack Compose + Material 3 + MVVM + Coroutines/Flow + Room Database**.

## المزايا المعتمدة
- **الهوية والشعار الرسمي:** دمج شعار "الكامل-طباعة الكروت" كأيقونة رسمية تكيفية (Adaptive Launcher Icon) وشعار داخل شاشة البداية، شاشة الدخول، وشاشة قفل التطبيق.
- **الطباعة الورقية A4 فقط:** توليد ملفات **PDF** عالية الدقة بمقاس **ISO A4** (شبكة كروت تصل حتى `6 × 30` كرت في الصفحة الواحدة) مع الطباعة المباشرة عبر خدمة طباعة أندرويد (`PrintManager`) ومشاركة وفتح ملفات PDF، مع حذف تام لمنطق الطابعات الحرارية.
- **دورة التوليد والإضافة والطباعة المدقّقة:**
  1. توليد الكروت محلياً ومنع التكرار مع عرضها مباشرة في بطاقات تفاعلية.
  2. إضافة الكروت إلى قاعدة البيانات المحلية (`alkamel_cards_printer.db`) على دفعات موثّقة مع شريط تقدم `1%..100%` وعداد فعلي، وتحول زر «خروج» إلى اللون الأزرق الملكي (`#1976D2`) عند الاكتمال.
  3. الانتقال المباشر إلى شاشة معاينة طباعة A4 وطباعة الكروت وتسجيل المبيعات تلقائياً.
- **إدارة متكاملة:** شاشة كروت يوزر مانجر (بحث بالتاريخ والفلاتر + استيراد TXT/CSV)، مصمم قوالب الكروت (مع سحب النصوص ورمز QR)، إدارة الباقات، الكروت المنتهية، المبيعات، التقارير وتصدير تقارير المبيعات PDF A4، وإعدادات الطباعة A4 وقفل التطبيق الاختياري (كلمة مرور / بصمة).

## البناء التلقائي لملف APK عبر GitHub Actions
يحتوي المشروع على سير عمل جاهز في `.github/workflows/android.yml` يقوم تلقائياً عند كل `push` إلى الفرع `main` أو عبر `workflow_dispatch` ببناء:
- `alkamel-card-printer-debug-apk` (جاهز للتثبيت والتجربة المباشرة)
- `alkamel-card-printer-release-apk` (نسخة Release مضغوطة عبر R8/ProGuard)
